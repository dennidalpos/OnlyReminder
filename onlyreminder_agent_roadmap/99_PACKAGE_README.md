# 99 — Package README

Questo pacchetto contiene la roadmap operativa per far sviluppare OnlyReminder a un agente AI in
step controllati.

## File principale

Aprire prima:

```text
00_MASTER_TRACKER.md
```

Il master è il tracker operativo senza storico. Va aggiornato solo cambiando:

```text
[ ] -> [x]
```

## Regola pratica

Passare all'agente un solo file numerato alla volta.

Per un MVP vendibile, usare il percorso:

```text
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 10 → 11 → 12 → 13 → 14 → 15 → 16 → 18
```

Gli step `09` e `17` sono più adatti a v1 completa/avanzata.
